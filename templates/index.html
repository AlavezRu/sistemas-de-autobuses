Cada ruta lleva su propio autobús de {{ total_asientos }} asientos, así que los lugares de una corrida no le quitan lugares a las otras. Quien se baja en un punto intermedio ocupa un asiento de toda la corrida.

¿Cómo se compra un boleto?

1. La ruta

Se escoge una de las tres corridas que salen de {{ origen }}.

2. El punto donde se baja

Se escoge dónde se baja el pasajero; ahí mismo se ve el pasaje que le toca.

3. La fecha del viaje

Se elige el día en el calendario; no se aceptan días que ya pasaron.

4. El asiento

Se muestra el mapa del autobús de esa corrida con los lugares libres de ese día; los ya vendidos no se pueden escoger.

5. El pasajero

Solo se escribe el nombre y el boleto queda apartado.
